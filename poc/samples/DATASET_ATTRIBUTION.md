# Dataset attribution

The prescription-image samples in this directory are privacy-redacted derivatives of images from:

- **Dataset:** Handwritten Medical Prescriptions Collection
- **Creator:** Mehak Singal (Kaggle username: `mehaksingal`)
- **Source:** https://www.kaggle.com/datasets/mehaksingal/illegible-medical-prescription-images-dataset
- **License listed by Kaggle:** MIT
- **Changes made:** identifying details were covered with opaque redactions; filenames were changed to describe test difficulty.

These files are included only for prototype OCR evaluation. They must not be used for diagnosis, prescribing, dispensing, or other clinical decisions.
